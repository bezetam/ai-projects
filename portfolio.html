NO. 004 — MULTI-AUDIENCE OUTPUT
Release Notes Agent

Feed it raw ticket data for a release, get back three tailored release notes generated from the same source — technical detail for engineering, plain language for customers, business impact for leadership. Runs here in-browser with your own Claude or Gemini key; a Python CLI version (with a template fallback for when no key is set) is also available on GitHub.

Stack
Python Vanilla JS Claude API Gemini API

Skill demonstrated: audience-specific prompt engineering, dual-provider architecture with graceful fallback, and iterating against real output — the first pass of the customer-facing version read like marketing copy, tightened after review to match a professional changelog tone.

Open project ↗ runs locally, no server needed
